基础设置

配置离线身份并查看本机服务状态

功能地图：想做什么 → 去哪一页 第一次用先看这里；点这一行可以收起（下次打开不再自动展开）
  • 给曲库起名 / 标白天傍晚夜晚 → 「命名与试听 → 曲名与时段」（主要工作区，第一次进去有「三步上手」）
  • 先听一段再决定 → 「命名与试听 → 试听工具」：试听播放器
  • 某个时段判定对不对 / 想改 → 「试听工具 → 时段依据复核」：看画面与判定值，可「按画面判定重写」或手动指定
  • 找同一首的不同版本 → 「试听工具 → 同款群核对」
  • 更新程序 / 看更新说明 → 「更新与维护 → 软件更新」
  • 确认 ffmpeg 等依赖是否就绪 → 「更新与维护 → 依赖检查」
  • 看程序日志 / 定位报错 → 「更新与维护 → 运行日志」
  • 出问题了，想给作者一份材料 → 「更新与维护 → 高级设置」最下面的「一键诊断包」：导出一个已脱敏的 zip 直接发过去
  • 怕数据丢 / 改错了想回退 → 「高级设置 → 数据备份与恢复」：立即备份、看某份备份里有什么、一键回到某个时间点（改时段和写曲名前程序也会自动留备份）
  • 换电脑 / 重装，要把整理成果带走 → 「高级设置 → 导出 / 导入」：导出一个 zip（含曲名、时段、歌词关联、信件；不含 API Key），在新机器上「从导出包导入」即可
  • 游戏崩了 / 崩在哪个模块 → 「高级设置 → 游戏崩溃记录」（点「解读崩溃报告」）
  • 启动慢在哪一段 → 「高级设置 → 读取启动耗时」
  • 游戏自己写了什么 → 「高级设置 → 游戏日志」（页面最底部，点「读取游戏日志」）
  • 挂界面补丁 / 改曲库目录 / 备份 → 「客户端与歌词 → 客户端挂载与存储」
  • 桌面歌词外观 → 「客户端与歌词 → 歌词设置」
  • 配置写信用的模型 → 「基础与设置 → AI 模型」
  • 记忆与信件 → 「信件与记忆 → 记忆」
  • 使用声明 / 隐私 / 开源许可 → 「基础与设置 → 声明与合规」
