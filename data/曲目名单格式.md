# 社区曲目名单格式

`catalog.json`：

    {
      "version": 1,
      "updatedAt": "2026-09-23T00:00:00.000Z",
      "license": "CC0-1.0",
      "entries": {
        "midi_8815_1786281418": "千本樱"
      }
    }

- `entries` 的键是曲库文件夹名 `midi_<编号>_<上传时间戳>`，值是曲名。
- **只允许这两个字段**。不要加用户名、路径、备注、时间之外的任何东西。
- 曲名长度 ≤ 80 字，且不能含路径、邮箱、网址、超长数字（见 `tools/sanitize.js`）。

## 怎么贡献

1. 在程序里命名完，点「提交到社区」，程序会在 `data/inbox/` 下生成一个小文件（只含你新增的条目）。
2. 用你的 GitHub 账号向本仓库提 PR。
3. 维护者跑 `node tools/sanitize.js check data/inbox/<文件>.json` 校验后合并进 `catalog.json`。

## 维护者命令

    node tools/sanitize.js check data/catalog.json          # 校验主名单
    node tools/sanitize.js export 本地命名.csv data/inbox/x.json   # 从本地命名记录导出
