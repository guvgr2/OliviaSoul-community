# 社区投稿目录（每人一个文件）

**每个用户的歌名单独存一个文件**（建议 `github用户名.json`），程序只读合并后的 `../catalog.json`。

    {
      "version": 1,
      "contributor": "some-github-user",
      "entries": {
        "midi_130991_1784281291": {
          "name": "稻香",
          "fps": ["<512 字符>", "<512 字符>", "<512 字符>"],
          "hash": "a1b2c3d4e5f60718"
        }
      }
    }

- `fps` 是 3 段音乐指纹（第 20s / 80s / 140s 起各 60 秒），由 `tools/fingerprint.js` 生成。
  **作用**：同一首歌在不同用户曲库里文件夹编号完全不同，只有指纹能认出"这是同一首"，
  让没听过的用户也能自动命名。
- **自动命名前必须多段校验通过**：至少 2 段相似度 ≥ 0.90 **且**没有任何一段低于 0.70。
  宁可留给人听，也不许填错。
- 指纹是单向派生数据（量化色度特征），还原不出音频，不含任何个人信息。
- **不要**放任何其它信息（不要身份信息、不要路径、不要设备信息）。
