# 使用说明

## 一、装好之后

打开界面里的 **「曲名与时段」** 页签。第一次进去会先问一次：

> 是否愿意分享你起的曲名？
> 只上传「曲名 + 3 段音乐指纹」；不会上传任何个人数据。
> 选「暂不分享」也能正常使用全部功能，只是不参与社区共享。

## 二、先让程序自动命名（省力顺序很重要）

1. 点 **「刷新名单」** —— 从开源仓库拉取社区曲目名单
2. 点 **「自动命名」** —— 程序对你的无名歌算指纹，跟名单比对，**命中的自动填名**
3. 剩下「名单里也没有」的歌，才需要你自己听

首次「自动命名」比较慢（要给每首算 3 段指纹），之后指纹有缓存，很快。

## 三、给剩下的歌起名

在同一个页签往下滚，就是试听台：

- 每首自动播放 15 秒片段
- `空格` 重播 · `回车` 写库并跳下一首 · `N` 换一段（每首最多 6 段）· `S` 跳过 · `←` 上一首
- 卡片上显示这首的 **BPM / 调性 / 时长**，以及**同编号下已有的名字**（照着起名用）
- 如果是**同款群**（音频实锤同一录音），会标注「★ 同款群 N 首会一起命名」，打一个名字全群一起填

听不出来就按 `S` 跳过，别硬猜 —— 猜错会污染社区名单。

## 四、时段识别

点 **「预览时段」**：程序读画面判断每首作品的白天/傍晚/夜晚，并列出每段视频的亮度值。
确认无误后点 **「写入时段」**：
- 只写入**从未设置过时段**的作品，你手动设过的不会被改
- 写库前自动备份数据库

## 五、把你起的名字分享给社区（可选）

点 **「生成投稿文件」**，填你的 GitHub 用户名，程序会生成一个只含
`编号 / 曲名 / 指纹 / 校验哈希` 的文件。把它提交到仓库的 `data/community/` 目录并提 PR 即可。

**不要**在投稿文件里加任何其它信息。

## 六、出问题了怎么办

- 所有写库操作前都会自动备份，位置：`<OliviaSoul 数据目录>\database\backup-*.sqlite`
- 试听片段缓存在 `<OliviaSoul 数据目录>\listen-clips\`，可以随时删
- 命名日志：程序目录下的 `记录\试听命名.csv`
## 七、系统必要依赖说明

本程序唯一的系统必要依赖是 **Microsoft Edge WebView2 运行时**（微软的网页控件运行时，界面靠它渲染）。

- 安装程序会**自动检测**：系统里没有就**自动静默安装**（需要联网，约 1 分钟）
- 如果自动安装失败（例如离线安装），安装程序会**弹窗明确告知你**："这是本程序运行的【必要依赖】"，并提示到微软官网搜索 "WebView2 Runtime" 手动安装
- 其余依赖（Node 运行时、ffmpeg、whisper 模型、npm 包）都**随程序一起打包**，你不需要安装任何开发环境

## 十、被杀软报毒怎么办

这个程序没有代码签名，而且会启动 node、调用 ffmpeg、扫描本地视频文件，行为特征容易被误判。
程序不含恶意代码，源码公开可查。遇到报毒可以：

1. **加排除项**：卡巴斯基 → 设置 → 威胁与排除 → 管理排除项 → 添加 → 选程序所在文件夹
2. **改用免安装版**：`Portable.zip` 比安装包少很多敏感行为，被误报概率更低
3. **提交误报**：<https://opentip.kaspersky.com/> 上传被报文件，选 Report a false detection，
   说明是开源学习项目并附仓库地址；通过后所有卡巴用户都不再被报

彻底解决需要代码签名证书（约 $10/月起，如 Azure Trusted Signing）。
