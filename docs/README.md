# docs 索引

本目录放的是**这个分支自己的**技术文档：现状说明书 + 流程/门禁。本文件是入口，只回答两件事：**这份文档讲什么**、**什么时候该翻它**。

> 现状说明书是在某个具体版本上写的，当前版本见 `repo/source/local-service/package.json` 的 `version`。
> 里面的行号会随开发漂移，**行号只当定位线索**，以源码为准；需要精确行号的文档都写了重跑方法。
