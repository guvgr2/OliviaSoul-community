## 1. 一句话结构

一个 Node 写的**本机服务**（兼 HTTP 服务端 + SQLite 数据库 + 业务逻辑），外面套**两个互相独立的桌面壳**（随包发布的是 C# WebView2 宿主，仓库里另有一份 Electron 壳），加一组**PowerShell 补丁脚本**（改游戏客户端文件），再加一套**只读探测工具**（不参与发布）。

- 服务主体：`repo/source/local-service/server.js`（4708 行，`createOliviaService`，:725）
- 随包桌面壳：`repo/source/local-service/native-host/`（C# + WebView2，`OliviaSoul.csproj`）
- 壳与服务的桥：`repo/source/local-service/desktop/node-host.js`（stdin/stdout 行协议）
- 前端页面：`repo/source/local-service/public/`（原生 HTML/CSS/JS，无框架）
- 客户端补丁：`repo/source/tools/*.ps1`（`patch-feapp-local.ps1` 等）
- 只读探测：`repo/source/renderer-probe/`（与上面的服务完全分离）

## 2. 运行形态与进程划分

当前代码里存在三条启动路径，**随包发布走的是第 1 条**：

| # | 形态 | 谁拉起服务 | 入口 | 备注 |
|---|---|---|---|---|
| 1 | 随包桌面版（C# WebView2） | 宿主进程起一个 **node 子进程**，node 进程内**同进程**调用 `createOliviaService()` | `native-host/OliviaSoul.csproj` → `native-host/NodeBackend.cs:59`（`LaunchProcess`）→ `desktop/node-host.js` → `desktop/controller.js:829` | 两个进程：宿主 exe + node |
| 2 | 只有本机服务（无壳） | 自己 | `node server.js`（`package.json:8` 的 `start` 脚本）→ `server.js:4705` `await service.listen(27149, "127.0.0.1")` | 浏览器访问 `http://127.0.0.1:27149/admin`（`server.js:2945`） |
| 3 | Electron 壳（仅开发） | Electron 主进程**同进程**调用 `createOliviaService()` | `desktop/main.js:535`（服务）、`:537`（`listen`） | `package.json` 里**没有** `electron` 依赖，`packaging/` 也不引用它（第 3.7 节） |

第 1 条的进程间约定（可核对）：

- C# 侧启动参数逐字为 `--root <UserData> --data-dir <UserData\database> --template <模板目录> --app-data <UserData> --usersettings <游戏配置> --executable <宿主exe> --parent-pid <宿主pid>`（`native-host/NodeBackend.cs:66-76`；这些目录的含义见 `docs/数据与状态文件.md`）。
- 就绪等待上限 30 秒（`native-host/NodeBackend.cs:53-54`，超时抛「等待本机服务启动超时」）。
- node 异常退出自动重启，最多 3 次（`native-host/NodeBackend.cs:100-102`；正常退出不重启，:118）。
- 行协议前缀是 `OLIVIA\t`（`desktop/node-host.js:7`、`native-host/NodeBackend.cs:18`）。
- 命令表在 `desktop/node-host.js:65-85`：`getLyrics / setLyrics / adjustLyricsOffset / lyricsPlayerControl / getSettings / setAutoStart / setClient / getClientStatus / mountClient / restoreClient / assertSoulExport / exportSoul / assertRemoteSoulExport / exportRemoteSoul / prepareUpdateInstall / shutdown`。
- 宿主还用 `--parent-pid` 做父进程存活检测（node 侧每 1 秒查一次）。

## 5. 桌面壳做什么

- **C# 壳（随包）**：宿主窗口内嵌 WebView2 打开 `http://127.0.0.1:<port>/admin`（Electron 壳同一写法见 `desktop/main.js:35-37`）；桌面歌词窗由宿主自己画（`native-host/Lyrics*.cs`），歌词帧走 `OLIVIA\t` 协议（`desktop/node-host.js` 的 `send`）。
- **`desktop/controller.js`（JS 侧控制器）**：端口挑选与占用探测（`:81-100`）、配置读写（`:137-155`）、开机自启（`:157-169`，计划任务名 `OliviaSoulAutoStart`，:24）、服务重启（`:829-844`）、客户端挂载与还原（`:653-700+`，详见 `docs/客户端补丁与挂载.md`）。
- **Electron 壳（`desktop/main.js`）**：自己一套窗口/托盘/IPC，并**另外实现**了一份挂载与还原逻辑（`mountClientService` :326、`restoreClient` :406），走的是同一个 `tools/*.ps1` 脚本。也就是说仓库里现在**并存两份客户端挂载/还原实现**（`desktop/main.js` 与 `desktop/controller.js`），随包发布路径用的是后者。
